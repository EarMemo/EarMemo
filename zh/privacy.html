隐私政策

最后更新：2026-08-09

耳记不收集、不上传、不分享任何个人数据，也不与任何外部服务器通信。你的数据只保存在你的设备上；唯一的例外是你主动开启「Wi-Fi 传输」时，文件仅在你自己的局域网内、设备之间直接传输。

留在你设备上的

你在耳记里做的一切——导入的音频、播放进度、收听统计、笔记、书签、设置——只保存在你的设备上。如果你在 iOS 设置里开启了 iCloud 备份，这些数据会随系统备份到你自己的 iCloud；耳记自己不发起任何同步、不读写任何远端服务。

耳记不做的事

  • 不向任何外部服务器发起网络请求。
  • 不内嵌第三方分析、广告或追踪 SDK。
  • 不申请通讯录、位置、照片、麦克风、通知权限。
  • 没有自己的账号系统、不需要登录。

Wi-Fi 传输

为了方便你从电脑或其他设备导入音频，耳记提供可选的「Wi-Fi 传输」。开启时，耳记会在你的 iPhone 或 iPad 上临时启动一个本地网页服务，让同一 Wi-Fi 下的浏览器直接连接你的设备。文件不会经过耳记的服务器或云端；关闭传输页面后，本地服务就会停止。不使用这个功能时，耳记不进行任何网络通信。

用到的系统 API

耳记使用标准 iOS API 保存设置、访问文件、后台播放、显示 Live Activities，以及在你开启 Wi-Fi 传输时建立可选的局域网连接。没有任何第三方服务或 SDK 会收到你的数据。

儿童隐私

耳记年龄分级 4+，对儿童安全。零收集政策对所有用户一视同仁。
