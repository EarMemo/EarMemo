隐私政策

最后更新：2026-05-18

耳记不收集、不上传、不分享任何个人数据。本 app 完全在你的设备上运行，不与任何服务器通信。

留在你设备上的

你在耳记里做的一切——导入的音频、播放进度、收听统计、笔记、书签、设置——只保存在你的设备上。如果你在 iOS 设置里开启了 iCloud 备份，这些数据会随系统备份到你自己的 iCloud；耳记自己不发起任何同步、不读写任何远端服务。

耳记不做的事

  • 不发起任何网络请求。
  • 不内嵌第三方分析、广告或追踪 SDK。
  • 不申请通讯录、位置、照片、麦克风、通知权限。
  • 没有自己的账号系统、不需要登录。

用到的系统 API

耳记仅使用标准的本地 iOS API：UserDefaults（保存设置和收听数据）、文件修改时间（用于按日期排序）、后台音频播放、Live Activities（用于睡眠定时器显示）。这些 API 都不涉及网络或第三方。

儿童隐私

耳记年龄分级 4+，对儿童安全。零收集政策对所有用户一视同仁。

联系方式与政策更新

如有疑问请发邮件至 earmemo@outlook.com。本政策如有更新，会随下一个 app 版本一起发布。
